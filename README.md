---

## ✨ Key Features

* **🌐 Multi-Language Support (i18n):** Seamless localization setup for global accessibility.
* **⚡ Modern Tech Stack:** Powered by Next.js 14 App Router and React for optimal performance and SEO.
* **🎨 Clean & Responsive UI:** Crafted with Tailwind CSS and modern UI components.
* **📱 Mobile First Approach:** Fully optimized for all screen sizes from desktop to mobile devices.
* **🚀 Fast Deployment:** Hosted on Vercel with automated CI/CD pipeline and custom domain configuration.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Localization:** `next-intl` / i18n setup
* **Deployment:** [Vercel](https://vercel.com/)
